# Webvire Technologies

Modern, high-performance 7-page IT agency website built with **HTML5, CSS3, JavaScript, Font Awesome 6 Icon Library, and AOS Animations**.

---

## Pages Included

- `index.html` - Home Page (3D Hero Canvas, Core Services, Portfolio Showcase)
- `about.html` - About Us (Company Growth Timeline & Tech Matrix)
- `services.html` - Services & Interactive Cost Estimator Widget
- `portfolio.html` - Portfolio Showcase & Category Filters
- `it-solutions.html` - Enterprise IT Solutions & Security Matrix
- `careers.html` - Careers Portal & Perks Grid
- `contact.html` - Contact Us & Interactive FAQ Accordion

---

## Core Tech Stack & Libraries

- **Icons**: Font Awesome 6 Icon Library CDN (`font-awesome/6.4.0`)
- **Animations**: AOS (Animate On Scroll `aos@next`)
- **Styling**: Vanilla CSS3 Custom Design System (`styles.css`)
- **UI Engine**: Modular JavaScript Engine (`script.js`)
